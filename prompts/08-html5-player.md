# Codex Prompt 08 — HTML5 lesson player

Build a responsive HTML5 player rendered from the canonical course model.

Requirements:
- Previous/Next, progress, optional slide menu and fullscreen;
- navigation modes: free/sequential/restricted;
- theme/layout system;
- quiz renderer integration;
- sanitize authored/AI content;
- no arbitrary script execution from course content;
- player renderer should also be reusable by SCORM export.
