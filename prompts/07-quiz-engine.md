# Codex Prompt 07 — Quiz bank and quiz editor

Implement persistent quiz authoring.

Priority renderers:
1. single choice
2. multiple choice
3. true/false
4. fill in blank
5. matching and ordering
6. drag/drop and image interactions later

Each item supports question, options, correct answer, explanation, correct/incorrect feedback, score, difficulty and objective links.

Scoring must be deterministic and covered by tests. The teacher can select/unselect AI-generated items without deleting them from the question bank.
